# App d'organisation

Un organisateur personnel pour téléphone : emploi du temps par demi-heure, tâches, notes,
sport, objectifs et motivation. Gratuit, sans compte : **tes données restent sur ton
téléphone**, rien n'est envoyé nulle part.

**L'app : https://emmajeuch.github.io/app-organisation/**

## L'installer

L'app s'installe depuis le navigateur, sans passer par l'App Store ni le Play Store.
Elle s'ouvre ensuite en plein écran depuis son icône, et marche sans réseau.

### Sur iPhone (Safari)

1. Ouvre le lien ci-dessus dans **Safari** (pas dans Chrome ni dans Instagram).
2. Touche le bouton **•••** en bas à droite, à côté de la barre d'adresse.
3. Touche **Partager**, puis **Sur l'écran d'accueil** (touche « Afficher plus » si tu ne le vois pas).
4. Vérifie que **Ouvrir en tant qu'app web** est activé, puis touche **Ajouter**.
5. Ouvre l'app avec la nouvelle icône « Orga » : c'est toujours par l'icône qu'il faut l'ouvrir,
   Safari et l'icône n'ont pas les mêmes données.

### Sur Android (Chrome) — à vérifier

Cette partie n'a pas encore été suivie sur un vrai téléphone Android.

1. Ouvre le lien ci-dessus dans **Chrome**.
2. Touche le menu **⋮** en haut à droite.
3. Touche **Ajouter à l'écran d'accueil** (ou **Installer l'application**), puis **Ajouter**.
4. Ouvre l'app avec la nouvelle icône.

Source : [blog des développeurs Chrome](https://developer.chrome.com/blog/a2hs-updates).
Chrome peut aussi proposer de lui-même une petite bannière pour installer l'app.

## Attention à tes données

- **Supprimer l'icône peut effacer tes données.** Pour la ranger, déplace-la plutôt dans un
  dossier ou sur une page de l'écran d'accueil que tu masques.
- Le téléphone peut aussi effacer les données d'une web app quand il manque de place.
- **Fais une sauvegarde chaque semaine** : Profil › Sauvegarde › Exporter, puis range le
  fichier dans Fichiers (iCloud Drive) ou Google Drive. Profil › Importer la remet en place.

## Les mises à jour

Elles arrivent toutes seules : ferme l'app et rouvre-la avec du réseau, deux fois de suite.
Tes données sont gardées. Le numéro de version est en bas de l'onglet Profil.
